# A6 – CSR monitor tab with world map

## Built
- The dashboard tab "Network" is now **CSR monitor** (route stays `#/network`). Order: Nodes worldwide, My rank, **Map**, Countries.
- Map card: inline SVG drawn by the shared `runner/assets/worldmap.js` (copy of the monitor's file, never edited). Dots are 2° areas sized by runner count; tapping a dot shows its label (e.g. `53°N 13°E · 2 runners`).
- Overview card "Ranking" → "CSR monitor", with an "Open CSR monitor" link; setting "Join ranking" → "Join the CSR monitor".
- Without `/v1/locations` (older monitor, error) the map has no dots and says "Location data is not available from the monitor."

## Demo with the mock monitor
`acceptance/a6/netmon.mjs` exports `startMapMonitor({locations})`, a mock of `/v1/network`, `/v1/nodes/{peer_id}` and `/v1/locations`.
Start it from a node script, point `[monitor] url` at it (loopback `http` is allowed), set `ranking.join = true`, run `csr run`
and open `http://127.0.0.1:8130/#/network`.

## Contract
`GET {monitor}/v1/locations` →
`{"locations":[{"lat":53,"lon":13,"count":2}],"located":6,"unlocated":2,"grid_deg":2,"updated_at":1792324800}`.
Cell centres only; 404 on older monitors. See `spec/monitor-public-api.md`.
