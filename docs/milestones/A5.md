# Milestone A5 – Testnet registration

A CSR node on testnet can register on chain with an attestation from the real CSR Network Monitor.

## What A5 adds
- **Testnet deployment.** `deployments/testnet.json` is embedded in the runner, so `csr float …`, `csr register …`, `csr runner-cell …` and `csr tx submit` work on testnet without a deployment file.
- **Real monitor defaults.** `config/networks/testnet.toml` points to `https://monitor-testnet.vericell.net` and its public key (also the owner of the config cell).
- **`csr register attest --out FILE [--json]`.** Sends `POST /v1/attest` with the peer id (from the node's `local_node_info`), the service public key, the network and the binding signature. The reply is verified (peer, service key, network, expiry, signature recovers to the monitor key) and written to `FILE`; `csr register prepare --attestation FILE` consumes it. Errors: `not_eligible` (the node needs successful checks in the last 24 hours with `[ranking] join = true`), other HTTP statuses are reported with their number.

## Flow
`csr identity` → fund → `csr float prepare-create` → `csr register attest --out att.json` → `csr register prepare` → sign → `csr tx submit`. See the testnet runbook in `docs/testing.md`.

Tests: `node --test --test-concurrency=1 acceptance/a5/p1.test.mjs acceptance/a5/p2.test.mjs` (mock node and monitor, no internet).
