# RFC drafts

This directory holds a **draft for review** of a CKB-VM host-interface RFC (`0000-ckb-vm-host-interface.md`). It is written in the format of `nervosnetwork/rfcs` but has not been submitted anywhere: the maintainer reviews it and submits it himself. The normative interface remains `spec/host-interface.md`; where the draft and the spec differ, the spec wins.
