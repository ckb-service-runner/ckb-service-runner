# csr-job.mjs – CSR job cell builder

One ES module, no imports, no dependencies. Works in browsers and Node ≥ 18. u64 values are `BigInt`.

## Install-free use

Copy `csr-job.mjs` into your project, or import it from a tagged GitHub raw URL (pin a tag, never a branch):

```js
import * as csr from 'https://raw.githubusercontent.com/ckb-service-runner/ckb-service-runner/<tag>/sdk/js/csr-job.mjs';
```

## API

| Function | Result |
|---|---|
| `encodeJob(job)` / `decodeJob(hex)` | molecule `Job` (layout of `contracts/schemas/csr.mol`) |
| `jobCell({ deployment, serviceId, job, extraCapacityShannons })` | `{ cellOutput: { capacity, lock, type }, outputData }` |
| `minJobCapacity({ deployment, serviceId, job })` | `BigInt` shannons: occupied capacity + `remainingRuns × (tip + maxFee)` |
| `jobCellDeps(deployment)` | cell deps of `csr-job-type` and `csr-job-lock` (`depType: 'code'`) |
| `watchPayload(outPoint, innerHex)` | `CSRW` header + inner payload |
| `loadDeployment(json)` | checks the content of `deployments/<network>.json` |
| `serviceId(codeHash, argsHex, dataHashes)` | service ID (D49, `spec/service-manifest.md`) |

`job` is `{ trigger, tipShannons, maxFeeShannons, maxCycles, payload, expiryBlock, refundLockHash, remainingRuns }`
with `trigger` one of `{ kind: 'OnDemand' }`, `{ kind: 'AtBlock', block }`, `{ kind: 'AtEpoch', epoch }`,
`{ kind: 'AtTimestamp', timestampMs }`, `{ kind: 'Every', blocks }`.

## Example: add a job cell to a CCC transaction

```js
import { ccc } from '@ckb-ccc/core';
import * as csr from './csr-job.mjs';

const deployment = csr.loadDeployment(await (await fetch('/deployments/testnet.json')).json());
const id = csr.serviceId('0x…code hash of your keeper…');

const { cellOutput, outputData } = csr.jobCell({
  deployment,
  serviceId: id,
  job: {
    trigger: { kind: 'AtBlock', block: 20_000_000n },
    tipShannons: 200_000_000n,        // 2 CKB for the runner
    maxFeeShannons: 100_000n,
    maxCycles: 70_000_000n,
    payload: '0x',
    expiryBlock: 20_100_000n,
    refundLockHash: userLock.hash(),   // where the rest goes back to
    remainingRuns: 1,
  },
});

// `tx` is your app's own transaction (e.g. the create/back transaction)
tx.addOutput(cellOutput, outputData);
tx.addCellDeps(csr.jobCellDeps(deployment));
await tx.completeInputsByCapacity(signer);
await tx.completeFeeBy(signer);
```

To make the job watch a cell, set `payload` to `csr.watchPayload({ txHash, index }, innerHex)`.
